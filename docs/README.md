# Documentación interna de AulaLista

Conocimiento normativo y didáctico que alimenta el generador. Si cambias algo aquí que afecte a los prompts, actualiza `shared/prompts.js` y ejecuta `python3 build.py`.

| `didactica/situacion-de-aprendizaje.md` | Anatomía de una SA y rúbrica de calidad interna |
| `fuentes.md` | Fuentes consultadas y lecturas pendientes |
